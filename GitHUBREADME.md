# Hi, I'm Wasiq 👋

I build systems that turn messy information into something people can understand and use, from claim-tracking pipelines for fact-checkers to booking flows for theatres. I'm based in London, studying Economics, Politics and Photography at A level, and I'm a TKS Innovate Honours graduate.

**Open to:** freelance web projects (especially theatres, arts and creative organisations) and collaborations.

---

### 🔍 Selected projects

| Project | What it does | Stack |
|---|---|---|
| **[Misinformation Monitor](https://github.com/itzwasiqsalman-cloud/misinformation-monitor)** | Pulls in news from 45 outlets, extracts checkable claims with an LLM, groups matching claims using sentence embeddings, and ranks them by spread, velocity and rhetorical risk for fact-checkers. Reviewed by experts at Full Fact and AllSides. | Python · LLMs · Sentence embeddings · Supabase · Streamlit |
| **[Videre Labs](https://github.com/itzwasiqsalman-cloud/videre-labs)** | Surfaces four persuasion signals in writing (emotional intensity, certainty language, attribution clarity, framing) so readers can spot when they're being nudged. | JavaScript · NLP |
| **[Theatre Royal Windsor concept site](https://github.com/itzwasiqsalman-cloud/windsor-theatre-demo)** | A pitch redesign with a scroll-driven hero, a 3D show carousel, and a seat-map booking flow modelled on the real auditorium. | React · TypeScript · Tailwind · Framer Motion |
| **[Portfolio](https://github.com/itzwasiqsalman-cloud/portfolio)** | My personal site. Plain HTML, CSS and JS, no framework. | HTML · CSS · JavaScript |
